# Data

- `colleges_slim.csv` – one row per school (1,944 Bachelor's-predominant, operating institutions) with selected Scorecard columns plus county ACS columns and a `Special` flag (service academies).
- `field_programs.csv`, `cip_names.csv` – earnings/programs per field of study (CIP 4-digit) and names.
- `us_states_topo.json` – U.S. state shapes (TopoJSON).
- `data.js` – GENERATED by `build/make_data_js.py`; do not edit by hand.

Caveats: Title IV students only; earnings are medians; missing/suppressed values are left out so coverage differs per variable; see the Scorecard earnings errata. Never invent or hand-fill values.
